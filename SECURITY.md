# Security Policy

## Supported Versions

The following versions are being supported:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

You can privately report a security issue using the "Report a vulnerability" button at https://github.com/jasontenpenny/url-branch/security.

You can also send security issues to `hello@jasontenpenny.com`.
